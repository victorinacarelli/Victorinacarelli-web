# Victorina Carelli · UX

Web portfolio de Victorina Carelli, diseñadora UX/UI: portfolio, asesorías, mini bio y contacto. En español e inglés.

Es un sitio estático (un solo `index.html`), así que está publicado en Cloudflare Pages (victorinacarelli.com.ar). Incluye robots.txt, sitemap.xml y 404.html para SEO; si sumás una página, agregala al sitemap.
